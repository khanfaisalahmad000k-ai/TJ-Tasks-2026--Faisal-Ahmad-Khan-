IRONFORGE FITNESS — Responsive Gym Website
==============================================
Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in one folder.
2. Open index.html in a browser, or use VS Code + Live Server.

Built only with:
- HTML5
- CSS3
- Vanilla JavaScript

Interactive features:
- Responsive navigation / mobile menu
- Smooth section navigation
- Membership plan selection
- BMI calculator
- Testimonial slider
- Contact form feedback
- Active navigation highlighting
- Animated ticker
- Hover effects and responsive layouts

REAL PHOTOGRAPHY UPDATE:
The site now uses real gym/workout photography from Pexels via image URLs in index.html. The selected photos are free-to-use according to the corresponding Pexels pages. For production, download the chosen photos into a local assets folder if you want the site to work without internet access.
